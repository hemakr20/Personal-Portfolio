# Portfolio Website

## Overview
A personal portfolio website for Hemalatha K, a MERN Stack Developer. Built with React and Tailwind CSS.

## Project Architecture
- **Framework**: Create React App (React 19)
- **Styling**: Tailwind CSS
- **Type**: Frontend-only (static website)

## Project Structure
```
src/
  components/     # React components (Header, Hero, About, Projects, Resume, Contact, Footer)
  assets/         # Images and static assets
  App.js          # Main app component
  index.js        # Entry point
public/           # Static public files
```

## Development
- **Port**: 5000
- **Host**: 0.0.0.0
- **Command**: `npm start`

## Deployment
- **Type**: Static deployment
- **Build command**: `npm run build`
- **Output directory**: `build`
